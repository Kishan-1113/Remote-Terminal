01

Dense Multilingual Vector Embeddings

Converts input into 384-dimensional vector space via intfloat/multilingual-e5-small (~130 MB). Normalizes representations across both English and Hinglish idioms.

q = model.encode([query], normalize_embeddings=True)[0]
02

Cosine Similarity Matrix Matching

Computes dot products across all 320+ pre-calculated intent representations. Enforces a strict 0.85 confidence threshold to eliminate hallucinations.

sims = emb @ q; intent = labels[np.argmax(sims)]
03

Hybrid Entity & Slot Extraction

Extracts target names via dual mechanisms: prepositional regex markers (naam ke, called) and dynamic stopword vocabulary filtering.

name = extract_name_by_marker(text) or extract_name_by_stopwords(text)
04

Template Interpolation & Safety Verification

Synthesizes commands from the verified 524-command registry. Flags destructive commands with explicit confirmation prompts to prevent data loss.

cmd = entry['template'].format(**slots)

FAQ & Knowledge Base

Frequently Asked Questions

Short, crisp answers about running and extending Project Terminal on your local machine.

Privacy

Does Project Terminal require an internet connection or cloud API keys?

100% Local & Private

No internet connection or API keys required. The entire neural embedding model (multilingual-e5-small) runs completely on your CPU with zero telemetry or data leaks.

Hinglish AI

How accurately does it interpret Hinglish and conversational phrasing?

2,190+ Reference Intent Vectors

It maps informal colloquial words (like "banao", "hata do", "chhupe hue files") to verified shell commands using semantic cosine distance, achieving >95% natural language accuracy.

Safety

How does the Safety Guard prevent accidental data loss?

Pre-Execution Confirmation

High-risk commands (like rm -rf, docker rm -f, or git branch -D) are flagged with "confirm": True and require explicit confirmation before execution.

Cross-Platform

Which operating systems are supported out of the box?

Windows, macOS & Linux

Works natively across all major platforms. The package includes run_windows.bat for Command Prompt/PowerShell and run_mac.sh / run_linux.sh for Unix bash.

Registry

What command ecosystems and tools are built into the registry?

524+ Production Templates

Covers Git branches, tags, stashes and remotes; Docker containers, volumes, networks and compose; plus Linux file permissions, disks, network sockets, and systemd services.

Customization

Can I add custom commands or company internal scripts?

Plug-and-Play Extensible

Yes. Add 3-5 example phrases to intents.py and bind the command pattern in command_registry.py. The AI engine automatically rebuilds indexes on restart.

Specs

What are the minimum system hardware and RAM requirements?

~300 MB RAM • Any Standard CPU

Requires standard Python 3.10+ and under 350 MB RAM. No dedicated GPU or CUDA drivers are needed—the quantized model runs effortlessly on budget laptops.

Performance

How fast is command translation inference on CPU?

< 45ms Response Time

Commands are classified and slot-extracted in under 45ms. Pre-computed embedding matrix operations ensure instant terminal responses with zero lag.
